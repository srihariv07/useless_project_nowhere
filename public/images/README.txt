========================================================================
USELESS™ Custom Product Images Directory
========================================================================

You can drop your custom product image files directly into this folder!

The website looks for images matching the following file names:

1. potato-gps.png        (GPS Tracker for Potatoes)
2. banana-peeler.png     (Autonomous Banana Peeler)
3. water-powder.png      (Instant Dehydrated Water Powder)
4. pedal-wheelchair.png  (Pedal-Powered Wheelchair)
5. wifi-rock.png         (Wi-Fi Enabled Rock)
6. square-wheel.png      (Aerodynamic Square Wheel)
7. left-handed-spoon.png (Ergonomic Left-Handed Spoon)

NOTE:
- You can use .png, .jpg, or .webp!
- If your filenames are different, simply update the `image` field in:
  `src/data/products.js`
- Until you add your images, the website will automatically display 
  the built-in custom SVG vector illustrations!
========================================================================
